# ADR 0008：资源整包快照与固定读取

| 字段 | 内容 |
| --- | --- |
| 状态 | 已接受并实施；实际接口与验证见 [L1-03](../implementation/work-items/L1-03.md)。 |
| 日期 | 2026-11-23。 |
| 范围 | 资源构建、安装、完整版本发布和读取，不建设执行器或业务资产仓储。 |

## 背景

L1-02 已有真实工作区文件保存，但 ArtifactIdentity 和文件位置都属于工作区。受管脚本、说明文档及模板由部署端提供，并需要在不同任务之间共享固定版本。为它们建立虚构工作区会混淆产物来源；依靠可变目录或最新版本又会使长任务的输入依据变化。

Hi3D 的[资源机制](../../hi3d/infrastructure/bundled-assets-and-script-tools.md)提供唯一维护源、物化映射、依赖和摘要核对的参考。其桌面原地部署、宿主冲突处理和安装戳快路径不直接成为 Vet3D 服务端的完整版本提交或内容一致保证。

## 决定与理由

1. **逻辑键与内容版本分开。** 用资源逻辑键命名维护对象，以清单原始字节指纹固定整包快照。确切引用为二者组合，不复用 ArtifactId，也不增加逐资源版本或 latest。整包变更使未改文件所属引用一起变化，是首期避免版本求解器的明确取舍。
2. **元数据单源，摘要单向派生。** 人工只维护资源声明和原文件，构建生成文件指纹表。源声明与安装清单共用资源解码规则，不各自维护枚举。安装端核对实际清单字节，不重写清单或回迁部署副本。
3. **完整目录发布。** 在同一文件系统的暂存目录完成复制、摘要和文件集合检查，再以 Linux 无覆盖重命名发布整个快照。已有目标拒绝覆盖；重新读取完整快照与原调用是否收到成功回执分别表达。
4. **安装权限与读取端口分开。** 可信 Operations 提供固定来源和预期指纹，业务取得只读固定版本实例。运行期不接受任意主机路径、安装命令或网络地址。安装和读取各自有有限 I/O 准入，不制造全局建模调度器。
5. **不设可执行投影。** 解释器和依赖是需求声明，实际环境检查留给 L1-05／L2。安装不 import 或执行资源，不把 Skill 文件变成自动注册的 Tool，不形成业务发布资格。
6. **恢复保留事实边界。** 重启后只凭原快照核对已发布目录；不认领临时目录、不自动补建损坏快照，不替 L1-04／L3-01 保存会话绑定。完整资源包提交不扩张为任务资产的多文件事务。

## 未采用的方案

| 方案 | 未采用原因 |
| --- | --- |
| 工作区产物接口包装资源库 | 强加错误归属并混淆用户素材与部署资源。 |
| 安装数据库加 installed／ready 缓存 | 当前没有独立消费者；文件和清单检查已经提供所需事实，额外状态会漂移。 |
| 每个资源的语义版本、版本范围及依赖下载 | 当前只有固定本地包消费者，提前建设求解器及网络分发会扩大范围。 |
| 直接覆盖已有资源目录 | 运行中的固定引用可能观察到部分更新或新旧混合。 |
| 只用 mtime／size 判定内容未变 | 元数据相同不保证字节一致，不能替代内容指纹。 |
| 构建时导入脚本推断依赖或跑安装 Hook | 引入执行权限与副作用，本项只处理声明和字节。 |
| 暂时 materialize 的路径作为永久资源身份 | 临时路径寿命与业务使用寿命不同，应先发布受管快照再交接。 |

## 依据与后果

Linux [rename(2)](https://man7.org/linux/man-pages/man2/rename.2.html)规定无覆盖重命名及同文件系统约束；[fsync(2)](https://man7.org/linux/man-pages/man2/fsync.2.html)说明文件同步不自动覆盖父目录项。当前目录发布仍须在目标文件系统实测，不能仅凭 API 名称宣称断电恢复。

当前 Debian／ext4 实测表明，跨父目录移动还需要可写的被移动目录根，以更新其 `..` 关联。实现因此先收紧文件及内部目录，保留暂存根可写，完成重命名后再收紧最终根并同步。重命名和最终改权之间不是单个原子操作；这段中断窗口按实施卡明确拒绝不完整快照，不以自动改权把未知结果认领为成功。

Python [importlib.resources](https://docs.python.org/3.14/library/importlib.resources.html)允许资源来自非普通文件位置，`as_file` 创建的临时对象可能在上下文退出时清理。当前直接使用可信本地包；后续若引入 wheel 内资源，仅把它作为来源，不把临时路径作为持久版本。

大文件流式交接、网络资源仓库、签名分发、滚动部署策略及垃圾回收等待真实消费者提出需求，不预付兼容层或运行时架构开关。当前只读字节交付不证明执行侧之后使用同一内容，后续隔离投递须按原引用再次核对。
