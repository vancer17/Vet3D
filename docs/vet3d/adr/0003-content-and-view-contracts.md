# ADR 0003：不可变文件内容与供应商无关的视图契约

| 字段 | 内容 |
| --- | --- |
| 状态 | 已接受；实现与验证状态由 [L0-03](../implementation/work-items/L0-03.md)维护。 |
| 日期 | 2026-11-23。 |
| 范围 | L0-03 的内容快照、定位与来源、模型空间、任务及操作图片语义和公开包归属。 |

## 背景

L0-02 已区分产物、模型版本、派生关系、执行产出及验收目标。下游仍需要明确文件身份所绑定的内容、文件现在如何定位、已知来源如何保留，以及不同调用中的图片承担何种作用。路径可变化，相同内容可以有不同业务身份，文件存在也不证明图片可解码或模型质量合格。

首期业务使用动物前、后、左、右、顶五向。历史 Hi3D 材料显示，主体侧别、画面朝向、API 槽位和官网标签并非同一命名层；普通四槽位能力不能决定 Vet3D 的五向要求。模型导入和审查也存在单位、局部或世界坐标、场景轴与实际物理尺度之间的差异。

Vet3D 面向由 BFF 调用的自主后端。约束应由数据校验及后续执行守卫落实，不能依赖正常链路中的持续人工审查，也不能因某个适配器暂时不可用而悄悄改变业务所需方向。真实验收、有限修订预算和终止结果在后续条目建立。

## 决定

1. 分开内容引用、工作区相对定位和实际接入出处。产物身份绑定不可变字节，变化内容使用新产物身份；沿用已有模型版本和关联类型，不再引入一层内容版本身份。
2. 将来源关系与执行关系继续交给 L0-02 的权威类型。接入出处用于说明实际取得材料的入口，不从标签、路径或缺少关系推导原件、拍摄来源或执行状态。
3. 建立供应商无关的规范模型空间和唯一五向语义。源尺度未知可以被保留；单位或轴的声明不代表已经完成物理标定或模型转换。
4. 区分任务长期要求与单次图片操作的输入。主体基准、必保特征和必需方向属于任务语义，操作主图、补充参考和目标方向属于本次操作，不将这些关系压缩成互斥图片角色。
5. 分开入选重建视图与仅供验收的参考。内容复制不能制造独立方向证据；后端能力不足应由适配器明确表达，不通过改变用途绕过业务要求。
6. 使用范围受限的 `artifacts` 和 `modeling` 包承载具体冻结结构、纯同步校验及已知尺度的标量换算，通过公共导出供后续消费者使用。实际读取、哈希、解码、模型转换、存储及供应商调用留在对应层实施。

确切公开类型、字段、坐标定义、输入约束、错误行为及验证结果只在 [L0-03 实施卡](../implementation/work-items/L0-03.md)维护；本 ADR 不复制接口定义。

## 评估过的替代方案

| 替代方案 | 本次未采用的原因 |
| --- | --- |
| 同一产物身份可任意覆盖内容，再增加内容版本 ID | 现阶段没有需要此额外身份层的消费者；会增加模型版本、证据及来源之间的关联复杂度。不可变产物可以让既有引用继续指向原字节内容。 |
| 将内容摘要直接作为产物身份 | 相同内容不一定承担同一业务身份；摘要也不应接管任务归属、登记或派生关系。 |
| 用绝对路径或文件名表达文件身份、来源和方向 | 路径可迁移且受平台影响，文件名不能证明来源或视觉方向；这些职责需要分别表达。 |
| 在文件记录内复制派生边、尝试 ID 或原件/派生互斥标签 | 会与 L0-02 的已有关系产生多个权威源；缺失关系也不足以支持二选一的来源结论。 |
| 沿用 Hi3D 的 API 四向名称和槽位作为业务枚举 | 历史不同路线的左右命名并不一致，且四槽位无法表达顶图参与重建的业务要求；供应商语义应由适配器处理。 |
| 使用一个互斥图片角色枚举概括主体基准、主图、参考和入选用途 | 同一图片可以在不同操作与关系中同时承担多种职责，互斥角色会丢失作用范围并制造重复枚举。 |
| 将验收顶图计入五向重建，或复制同一文件换身份补齐方向 | 能满足表面数量但缺少实际重建输入与独立方向依据，会让结构校验错误放行。 |
| 对未知源尺度默认一米，或将单位声明视为物理尺寸正确 | 普通 RGB 及任意生成模型没有自动提供实际尺寸依据；默认值会把未知变成错误的物理承诺。 |
| 本项同时实现图片解码、摘要读取、模型变换及供应商适配 | 会把纯语义与外部执行混合，提前决定尚未选定的资源和执行接口，也无法用本项内存测试证明真实链路。 |
| 建立全局 contracts 容器、镜像 Protocol 和可切换校验模式 | 当前稳定类型可直接使用；额外包装和架构开关没有实际消费者，并容易把不相关职责聚集到公共包。 |

## 后果与边界

消费者需区分文件身份、内容声明、定位和来源，并明确自己处理的是任务要求还是具体操作输入。更改字节内容需要新的产物身份，既有证据、版本及来源不能在不知情的情况下转指另一份内容。

校验只覆盖调用方提供的数据，不能证明摘要真实、文件可读、位置安全、图像方向正确、当前选集有效或物理尺度正确。不可变内容的持久登记、并发一致性、实际读取时复核及恢复仍由后续服务负责。

显式方向与用途有助于识别适配器能力缺口，但不产生视觉判断能力。即使结构有效，真实动物身份、姿态、比例、非对称特征及跨图一致性仍需要实际模型与验收证据；这些检查不得由字段完整性或复制文件代替。

本项不改变 Demo，不新增 HTTP、数据库、端口或配置，也不宣称 M0 已完成。后续扩展需要实际消费者与对应验收，避免把两个窄包扩展为所有业务对象和执行状态的公共容器。
