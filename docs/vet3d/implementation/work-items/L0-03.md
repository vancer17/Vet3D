## 3. 输入、输出与权威状态

### 文件快照、定位与出处

| 公开类型及字段 | 语义与约束 |
| --- | --- |
| `ContentFingerprint(sha256, byte_size)` | `sha256: str` 为 64 个小写十六进制字符组成的完整 SHA-256 摘要；`byte_size: int` 为非负字节数，不接受布尔值。通用文件允许零字节，不证明摘要与实际文件匹配。 |
| `FileReference(artifact_id, content)` | `artifact_id: ArtifactId` 绑定 `content: ContentFingerprint`；不重复保存工作区、路径或来源边。 |
| `WorkspaceRelativePath(value)` | `value: str` 为非空 UTF-8 相对 POSIX 路径；拒绝绝对路径、反斜杠、盘符或 URI 协议前缀、空路径段、`.`、`..` 和控制字符。不修剪、规范化、展开变量或读取磁盘。 |
| `WorkspaceFileLocation(artifact_id, relative_path)` | 关联 `ArtifactId` 与 `WorkspaceRelativePath`；工作区归属从 L0-02 的产物记录解析，不再次存储。 |
| `ImportOrigin(artifact_id, source_label)` | 关联 `ArtifactId` 与非空 UTF-8 出处文字，原文保留；不把文字转换为读取地址，也不保证其真实性或完整性。 |

上述均为具体冻结类型。产物 ID 在本契约中绑定不可变字节内容，内容变化必须使用新的产物 ID；本项不再创建 `ContentVersionId`，也不以路径或摘要替代产物身份。

文件定位独立表达工作区内的相对位置，不把当前操作系统的绝对路径嵌入内容身份。定位记录不证明文件存在、可读、仍处于工作区内或没有符号链接；这些事实由后续实际访问边界核验。

接入出处只表达调用方提供的实际接入标签，不反推拍摄者、原始性、可信度或生成方式。`Derivation` 继续是已知来源产物之间的唯一派生关系，`AttemptOutput` 继续是已知尝试产出关系；本项不复制同义的来源边或执行边。缺少某条边仍不能推断原件或未执行。

同样内容可以属于不同产物身份，复制文件或更换产物 ID 不会使它成为另一份方向证据。摘要只表达字节快照，不证明图片有效、方向正确、主体一致或当前已选定版本仍然有效。

### 模型单位与坐标

规范长度使用米，角度使用弧度。规范坐标采用右手系：`+X` 为动物自身右侧、`+Y` 为头端、`+Z` 为背侧。

`CameraOrientation(viewpoint, image_up)` 使用两个整数三元组表达观察者所在方向及画面上方向，构造时校验它们均为有符号单位坐标轴且相互正交，分量不接受布尔值。记录不含相机距离、焦距或完整位置，也不据此反推业务方向。`camera_orientation(direction)` 是由业务方向取得相机约定的唯一派生入口，不另外维护同义方向枚举。相机面向主体，约定如下：

| `ViewDirection` | `viewpoint` | `image_up` |
| --- | --- | --- |
| `FRONT` | `(0, 1, 0)` | `(0, 0, 1)` |
| `BACK` | `(0, -1, 0)` | `(0, 0, 1)` |
| `LEFT` | `(-1, 0, 0)` | `(0, 0, 1)` |
| `RIGHT` | `(1, 0, 0)` | `(0, 0, 1)` |
| `TOP` | `(0, 0, 1)` | `(0, 1, 0)` |

`SourceScale(metres_per_unit: float | None)` 使用 `None` 表达未知；已知值接受普通整数或浮点数，不接受布尔值，且必须为正有限数。`to_metres(value, *, scale)` 接受普通整数或浮点数形式的有符号有限标量，返回米制 `float`；源尺度未知时即使输入为零也拒绝，输入非有限、无法表示为有限浮点数或换算结果溢出时同样拒绝。

源模型尺度未知时必须保留未知，不默认按一米解释，也不声称已有真实物理尺寸。单位或坐标声明不表示已经执行转换；实际导入、变换、外部资源解析及几何核验由后续处理服务负责。

### 五向及参考图片语义

前、后、左、右、顶只有一个业务方向枚举 `ViewDirection`，由 `modeling` 拥有，为包含 `FRONT`、`BACK`、`LEFT`、`RIGHT`、`TOP` 的 `StrEnum`。供应商槽位、界面标签、文件名和相机轴不是另一个可相互替代的业务方向来源。供应商字段及槽位由适配器显式映射，不进入本项的五向契约。

| 公开类型及字段 | 语义与约束 |
| --- | --- |
| `TaskReferences(task_id, subject_reference_id, preserve_features, required_directions)` | `task_id: TaskId`、`subject_reference_id: ArtifactId`、`preserve_features: tuple[str, ...]` 及非空 `required_directions: frozenset[ViewDirection]`；必保要求元组可为空，已有条目必须为非空白 UTF-8 文本并保留原文，不据此确认要求充分。 |
| `ImageOperationReferences(main_image_id, supplementary_ids, target_direction)` | 主图为 `ArtifactId`，补充参考为 `frozenset[ArtifactId]`，目标为 `ViewDirection`；目标指希望产出的方向，不是输入图的实际观察方向。主图不可再次列为补充参考，主体基准可与主图相同或不同。 |
| `ReconstructionView(artifact_id, direction)` | 入选重建图与明确业务方向；`direction` 不能未知。 |
| `ReviewReference(artifact_id, direction=None)` | 仅供验收的参考图；`direction: ViewDirection | None` 允许未知，不因标有方向就成为重建输入。 |
| `SelectedViews(reconstruction, review_only)` | 两字段分别为 `ReconstructionView` 与 `ReviewReference` 的元组；全部入选产物身份唯一，重建方向唯一。构造时允许空元组，能否满足必需方向由选集校验判定。不包含候选池和其他阶段的全部图片。 |

任务级主体基准、必保特征及必需方向表达同一任务的要求；操作级主图、补充参考及目标方向表达一次具体图片操作的输入。主体基准不因本轮选择主图而自动改变，一张图片可以在不同关系中发挥作用，因此不建立互斥的 `ImageRole` 分类。

入选重建视图与仅供验收的图片分别表达。必需五向时，四张入选重建图加一张顶视验收参考不能满足要求；同内容复制后换一个产物 ID，也不能填充另一个业务方向。结构校验不判断图片实际拍摄方向、动物身份、跨图一致性或必保特征是否可见。

### 校验、输出及状态边界

调用方提供已构造的身份、内容声明、引用关系和视图要求。本项只校验本次提供的数据，不建立持久权威状态、全局产物注册表或另一套业务状态枚举。

| `artifacts` 入口 | 核对范围 |
| --- | --- |
| `validate_file_reference(reference, *, artifact)` | `FileReference` 与 `ArtifactIdentity` 精确匹配产物身份，不验证文件存在。 |
| `validate_content_binding(existing, candidate)` | 两个 `FileReference` 必须为同一产物 ID 且同一指纹；不同 ID 不在此入口比较为同一绑定。 |
| `validate_content_observation(reference, *, observed)` | 将调用方提供的观测指纹与预期指纹比较，不自行计算摘要或读取字节。 |
| `validate_file_location(location, *, reference)` | 定位与内容引用指向同一产物，不解析真实路径。 |
| `validate_import_origin(origin, *, reference)` | 出处与内容引用指向同一产物，不解释出处文字。 |
| `validate_file_set(references, *, artifacts)` | `tuple[FileReference, ...]` 与 `tuple[ArtifactIdentity, ...]` 的身份集合精确对应；缺失、多余、重复均拒绝。通用集合可以为空或跨工作区，不替代具体业务作用域校验。 |

`modeling` 的三个入口如下。共同的关键字参数为 `task: TaskIdentity`、`files: tuple[FileReference, ...]` 及 `artifacts: tuple[ArtifactIdentity, ...]`；操作及选集入口另接收关键字参数 `references: TaskReferences`。

| 入口 | 本次解析范围 |
| --- | --- |
| `validate_task_references(references, *, task, files, artifacts)` | 只解析任务主体基准。 |
| `validate_operation_references(operation, *, references, task, files, artifacts)` | 解析主体基准、操作主图及补充参考的身份并集。 |
| `validate_selected_views(selection, *, references, task, files, artifacts)` | 解析主体基准、全部入选重建图及仅验收参考的身份并集。 |

这些入口要求文件及产物记录恰好解析主体基准与本次实际用图的 ID 并集，不要求提供任务中未被当前操作使用的图片；同一图片可通过多个语义关系被引用，但解析记录不得重复。所有图片必须与任务同属一个工作区，字节数必须大于零。选集中的重建方向必须覆盖 `required_directions`，重建文件内容指纹不得重复，即使它们使用不同产物 ID；验收参考不能填补缺少的重建方向。

所有校验均同步执行，成功返回 `None`。字段或记录类型错误抛出 `TypeError`；文件契约错误抛出 `ArtifactContractError`，建模契约错误抛出 `ModelingContractError`，两者均为 `ValueError` 子类。建模入口复用文件校验时保留 `ArtifactContractError`；L0-02 的既有错误类型也不被本项改写，不包装成新的状态或质量结果。

同一产物 ID 的不可变内容约束需要由后续登记与存储边界在历史记录上维护；本项不能凭有限输入证明跨调用或持久全局一致。旧内容指纹、来源、选定视图或任务要求发生变化时，下游应重新核对其引用的确切输入，不能沿用不再匹配的结论。

本项不输出文件、报告、发布版本、加载回执或验收通过状态。模型版本及证据目标继续引用 L0-02 的权威类型，文件内容快照不能代替模型版本或验收身份。

## 4. IoC 与暴露方式

两包通过各自 `__init__.py` 提供公共导出，跨包仅从公共导出使用类型。`artifacts` 使用 `identity` 的身份；`modeling` 使用所需的公共身份和文件引用。稳定数据结构及同步校验直接使用具体实现，不增加镜像 Protocol、全局 `contracts` 容器或服务定位器。

调用边界提供身份、内容声明和业务要求。本项不自行装配文件系统、解释器、模型、存储或日志处理器，也不把环境 readiness、运行制品版本或部署配置带入逐轮业务请求。

本项没有需要选择的运行适配器；测试以参数和显式记录构造输入，不引入 Mock 模式业务配置。后续实际文件服务和模型适配器拥有其端口和装配职责，本项不预建未使用的端口。

## 5. 正常流程与副作用

| 步骤 | 输入与分支 | 状态及文件变化 | 可观察输出 |
| --- | --- | --- | --- |
| 构造内容引用 | 调用方提供产物身份、摘要及字节数；定位和接入出处独立提供。 | 不读取文件，不计算摘要，不建立登记记录。 | 满足已定义约束的不可变记录，或明确输入错误。 |
| 构造模型及视图语义 | 调用方提供源尺度声明、任务要求及具体图片操作输入；相机约定由方向派生。 | 不转换模型或坐标，不查看、生成或修改图片；已知源尺度可用于单独标量换算。 | 可供上层消费的数据或标量结果，不附带视觉质量及物理标定结论。 |
| 核对关联与选集 | 核对本次引用、同一内容声明、必需方向和两类视图用途。 | 不补齐图片，不改写业务要求，不重排供应商槽位。 | 成功返回 `None`，或抛出对应契约错误。 |
| 交给后续服务 | 后续消费者按确切引用自行执行其读取或处理职责。 | 本项不发起网络、磁盘或后台动作。 | 不把契约成立解释为实际资源已可用。 |

以上流程的实际执行证据见第 7 节。没有文件创建、覆盖、事务提交、通知或外部保存副作用。

## 6. 失败、取消与恢复

| 情形 | 本项边界 |
| --- | --- |
| 内容声明、定位或类型无效 | 抛出对应契约错误或 `TypeError`，不读取文件补证，不自动修正摘要、身份或路径。 |
| 同一身份关联冲突内容 | 本次输入中可见的冲突应拒绝；不能通过换一个路径隐藏冲突，也不声称已查询所有历史记录。 |
| 必需方向缺失、用途替换或复制内容占用不同方向 | 拒绝不满足当前要求的选集，不将验收图提升为重建图，不复制或镜像图片补齐方向。 |
| 后端不支持业务所需方向 | 本项不提供供应商能力探测；后续适配器应明确返回不匹配，不能据环境或槽位数量悄悄修改任务要求。 |
| 源尺度未知、标量换算非法或未实际执行空间转换 | 未知尺度可以保留，不能用于 `to_metres` 换算；非有限值或溢出拒绝，不能补造物理尺度正确或模型转换完成的结论。 |
| 文件已经变化、消失或位置指向其他内容 | 本项不监控磁盘。实际读取服务需重新核对所读内容与快照；内容变化按新产物处理，不能覆盖原身份的字节事实。 |
| 同时校验、调用中断、进程退出或重启 | 各次使用调用方输入，没有本项拥有的可变全局状态、持久账本或恢复句柄；再次校验不是恢复旧执行。 |
| 本地进程、远端 pending、提交或回执不明 | 不适用；本项不启动执行，不提交远端作业，不实现取消或重试预算。 |
| 部分文件写入、报告失败、并发替换或事务中断 | 不适用；本项无落盘副作用，不能对未来文件服务的恢复作保证。 |
| 结构成立但视觉或业务验收不足 | 不补造 `pass`，保留当前引用与业务要求；真实验收、修订预算及终止结果由后续条目负责。 |

本项为纯同步调用，不添加超时、取消端口或恢复配置。输入在构造后不可变，不意味着外部文件和执行环境也被冻结。

## 7. 验收计划与执行记录

| 检查项 | 方法与预期 | 实际证据与结论 |
| --- | --- | --- |
| 内容引用与身份 | 合法摘要及字节数、错类身份、非法输入和冻结行为；同一身份的可见内容冲突被拒绝。 | 文件契约测试共 15 项通过，覆盖合法引用、摘要规范、长度类型、冻结行为、内容绑定与观测错配；零字节仅在通用文件层允许。 |
