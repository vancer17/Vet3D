## 2. 前置依赖与接口归属

本项无其他实施条目前置。宿主与模块选择已经接受，原因及替代方案见 ADR；运行环境和放行依据见本卡实际验证记录。

`application` 拥有 `DemoRequest`、`DemoReply`、具体类 `DemoService` 和其唯一依赖端口 `DemoPort`。稳定的 `DemoService` 不再套一层同义 Protocol。`DemoPort` 只描述本项确实需要替换的异步执行依赖，正常演示适配器和受控测试替身使用同一请求、回复类型。

跨包引用通过各包的 `__init__.py` 公共导出；具体适配器依赖应用包拥有的端口，应用包不导入适配器、Bootstrap 或既有 Hi3D 参考工具。根包不进行有副作用的全局装配。

## 3. 输入、输出与事实边界

| 对象 | 当前语义 |
| --- | --- |
| `DemoRequest` | 冻结的输入对象，只有 `text: str`；由应用服务校验长度为 1～256 个 Python 字符、可编码为 UTF-8，且不能全部为空白。校验不修剪、不转换、不规范化原文本。 |
| `DemoReply` | 冻结的回复对象，只有 `text: str`；成功回复与请求原文本完全相同。 |
| `DemoPort.execute` | 异步接收 `DemoRequest` 并返回 `DemoReply`。 |
| `DemoService` | 具体应用服务，消费上述端口并执行本项输入、输出边界；不创建具体适配器。 |
| 调用事实 | 一次函数调用的回复或异常是该次结果；CLI 退出码属于调用入口的呈现，不另建同义业务状态枚举。 |
| 调用关联 | Bootstrap 为日志关联一次调用；关联串不成为每次请求的业务字段，不作为工作区、作业或制品身份。 |

请求不包含环境 Settings、readiness、解释器版本、实现选择或运行实例事实。没有持久化、缓存、重试、恢复句柄或后台作业；重新调用是新的演示调用，不宣称续接旧任务。

## 4. 装配与调用入口

| 入口 | 当前语义 |
| --- | --- |
| `assemble_application(port=...)` | 显式接收端口实现并构造 `DemoService`；测试通过此入口注入受控替身。 |
| `build_demo_application()` | 构造正常演示装配，明确使用 `DemoAdapter`。演示适配器可以实际执行文本回传，但不是真实产品模型。 |
| `invoke_demo` | 宿主的一次异步调用边界，`timeout_seconds` 为正有限秒数，默认 5 秒，零重试；管理宿主超时与取消，不改变应用请求或回复语义。 |
| `vet3d-demo --text ...` | 非交互验收入口。成功时 stdout 输出单个 JSON 对象，形如 `{"text":"原文本"}`；日志写 stderr。 |

Bootstrap 负责显式装配及日志初始化。依赖通过构造参数传入，不提供 Mock 模式、架构开关、全局服务定位器、环境驱动的动作变体或兼容别名。本项不注册 LLM Tool，不建立 Skill 或其他领域的空壳接口。

## 5. 正常流程与日志

1. CLI 解析参数，通过 Bootstrap 初始化日志并完成显式演示装配，构造请求。
2. 调用边界建立关联串，在截止时间内执行一次应用请求。
3. 应用服务校验输入，非法输入不调用依赖；有效输入只调用依赖一次。
4. 应用服务取得并校验回复；CLI 序列化并写出回复。
5. CLI 根据调用及输出的实际结果返回退出码。

默认日志级别为 INFO，仅写 stderr；使用短固定消息和调用关联串，宿主不主动记录请求正文。异常只在负责处理该异常的边界记录一次堆栈，其他层不重复记录后再次抛出。诊断保留异常栈及异常消息，依赖自行附带的内容可能出现在日志中；本项没有全量扫描或脱敏机制。格式化后单条记录最多 4096 个字符，不计行终止符；不累积无界内存缓存，不创建日志文件。本项不实现文件轮转或完整 Operations。

控制台输出为同步写入，本项验证单次演示调用的有限日志量；并发部署的采集吞吐、背压及非阻塞输出尚未验收，不能据此声明生产日志链路已经就绪。

开始、成功或交付阶段的日志写出失败直接使当前入口失败；依赖已经完成时，这种输出故障不能改称依赖失败。记录异常终态时如果日志也写出失败，保留原取消、超时或依赖异常，并通过异常原因链附加日志故障，不能用日志错误覆盖原调用结果。

## 6. 失败、取消与恢复

下列 CLI 退出码映射以诊断通道可用为前提。stderr 也无法写入时允许异常继续传播，安装入口以非零状态退出，不能保证仍由 `main` 正常返回对应数值。

| 情形 | 结果与边界 |
| --- | --- |
| 非法输入或 CLI 参数错误 | 返回退出码 2；不调用演示依赖。 |
| 依赖执行或回复校验失败 | 返回退出码 1；不自动重试，不补造回复。 |
| 依赖自行抛出 `TimeoutError` | 属于依赖失败，不能冒充宿主截止时间到达；CLI 返回 1。 |
| 宿主截止时间到达 | 通过 `InvocationTimeoutError` 表达；CLI 返回 124。取消当前调用并等待其协作式清理，零重试。 |
| 调用方取消 | 清理后继续传播取消，不转换为普通成功或业务失败；CLI 取消出口为 130。 |
| 回复已取得但 stdout 写出失败 | 返回 1，并明确这是输出失败；不能断言依赖失败，也不能据此重跑依赖。 |
| stderr 写出失败 | 开始、成功或交付阶段直接失败；异常终态保留原异常，以 `__cause__` 附加日志故障。诊断通道故障不能覆盖原取消、宿主超时或依赖异常。 |
| 进程崩溃或宿主重启 | 没有持久调用历史、恢复句柄或回执不明账本；内存中的调用事实不恢复。再次调用执行新的请求，不是恢复原调用。 |
| 正常回复写出 | 返回 0。 |

截止时间是协作式异步调用边界，不是对阻塞事件循环或拒绝取消的实现提供强制抢占保证。本项没有子进程、远端受理、文件发布、重启恢复或业务候选验收；这些边界不从本次演示推导为已实现。
