## 3. 输入、输出与权威状态

### 身份边界

公共身份类型为 `WorkspaceId`、`TaskId`、`SessionId`、`TurnId`、`JobId`、`AttemptId`、`ArtifactId`、`ModelFamilyId`、`ModelVersionId`、`EvidenceId` 和 `AcceptanceId`。这些类型均为具体的冻结类型，只有 `value: UUID` 字段，构造时要求完整 UUID4 对象。关系字段使用各自具体身份类型，不能直接传裸 UUID 或字符串；即使底层 UUID 相同，不同具体类型也不是同一身份。

各类型提供 `parse(value: str) -> Self`，只接受小写、带连字符的完整规范 UUID4 文本。非规范文本直接拒绝，不自动清理、转换大小写或补齐连字符。构造与解析都不生成随机值；调用边界负责提供 UUID。本包不通过名称、路径、时间或供应商标识推导身份。

显示名称不参与身份判断。相同显示名、文件名或内容不自动表示同一对象；校验入口只检查本次提供的记录和引用，没有全局注册表、去重库或持久唯一性保证。

### 不可变关系与目标

| 类型及字段 | 本项语义 |
| --- | --- |
| `TaskIdentity(id, workspace_id)` | 任务归属一个工作区，允许没有会话。工作区只以 `WorkspaceId` 引用，不在本项建立工作区实体或登记库。 |
| `SessionIdentity(id, task_id)` | 会话归属一个任务；是任务可选的执行上下文，不等于外部引擎线程，不重复保存工作区字段。 |
| `TurnIdentity(id, session_id)` | 轮次归属一个会话；可包含多次模型和工具调用，不等于一条人工消息或一次模型采样。 |
| `JobIdentity(id, task_id)` | 本地作业表达任务内的具体执行意图，不把供应商任务字符串用作内部身份。 |
| `AttemptIdentity(id, job_id)` | 一次执行尝试归属一个作业；原尝试续查沿用身份，轮询本身不建立新尝试。本项不调度执行或重试。 |
| `ArtifactIdentity(id, workspace_id)` | 原件与派生件共用产物身份；没有文件路径、内容格式、原件/派生状态或可读取保证。 |
| `ModelFamilyIdentity(id, workspace_id)` | 家族归属一个工作区；归组关系不自动表示版本派生关系。 |
| `ModelVersionIdentity(id, family_id, artifact_ids)` | 版本归属一个家族，`artifact_ids` 为非空 `frozenset[ArtifactId]`；不规定内容格式或文件角色。 |
| `ArtifactSetTarget(artifact_ids)` | 目标为非空 `frozenset[ArtifactId]`。 |
| `ModelVersionTarget(version_id)` | 目标为确切 `ModelVersionId`，不是家族、最新版本或目录选择。 |
| `EvidenceIdentity(id, target)` | 证据引用其观察目标；记录存在不证明已经取得文件或完成观察。 |
| `AcceptanceIdentity(id, target, evidence_ids)` | 验收记录引用被验目标和 `frozenset[EvidenceId]`；证据集合允许为空，任何集合大小都不表示 `pass`。 |
| `Derivation(output_id, source_ids)` | 输出产物关联非空 `frozenset[ArtifactId]` 来源集合，不能直接包含输出自身；不保证全图无环。文件内容与接入出处见 [L0-03](L0-03.md)。 |
| `AttemptOutput(attempt_id, artifact_id)` | 已知的尝试产出边，独立于派生边；不要求每条本地派生关系都创建一次尝试。 |

目标的唯一公共联合为 `ReviewTarget = ArtifactSetTarget | ModelVersionTarget`。集合字段要求 `frozenset`，记录及其字段类型在构造时校验。两种目标不隐式互转，也不维护同义的目标类别枚举。

没有派生边不能推断某个产物是原件，没有尝试产出边也不能推断未执行。校验针对调用方本次提交的关系，不从环境、磁盘、会话历史或远端服务补证。

后续 Agent 接入中的任务与原生会话关联由 [L2-02](L2-02.md)维护；上述类型不要求给每次原生文件读取、脚本编辑、预览或诊断分配业务 Job／Attempt，也不要求把运行时标识解析为内部 UUID4。

本包没有持久权威状态源。调用方提供的不可变身份及关系是本次校验输入；校验结论只约束该输入，不确认外部对象真实存在、权限有效、动作完成、版本发布或质量通过。

### 局部校验入口

| 入口 | 调用方提供的记录及核对范围 |
| --- | --- |
| `validate_session` | 会话与任务，精确核对直接父引用。 |
| `validate_turn` | 轮次与会话，精确核对直接父引用；不宣称已经核对会话所属任务或工作区。 |
| `validate_job` | 作业与任务，精确核对直接父引用。 |
| `validate_attempt` | 尝试与作业，精确核对直接父引用；不宣称已经核对完整上游归属。 |
| `validate_derivation` | 派生边、输出产物与来源产物元组，核对确切引用和同一工作区。 |
| `validate_attempt_output` | 产出边、尝试、作业、任务与产物，核对完整归属链及产物与任务同属一个工作区。 |
| `validate_model_version` | 版本、家族与产物元组，核对确切引用及全部产物与家族同区。 |
| `validate_artifact_target` | 产物集合目标与产物元组，核对确切集合及同区。 |
| `validate_version_target` | 版本目标、版本、家族与产物元组，核对目标版本及家族、产物归属。 |
| `validate_acceptance` | 验收记录与证据元组，只核对证据引用及目标匹配；目标实体需另用上述目标校验入口解析核对。 |

所有校验入口均为同步函数，成功返回 `None`，失败抛出异常；没有另一个布尔状态、质量结果或全局有效性报告。

涉及记录元组的入口要求记录 ID 集合恰好满足引用，缺少、多余或重复记录均拒绝。引用正确不表示这些实体存在于某个数据库；校验不访问数据库，也不对全局图作结论。

验收目标为产物集合时，每份证据允许只观察被验产物集合的非空子集；这不保证业务覆盖充分。验收目标为模型版本时，证据必须引用同一个版本 ID。两种目标之间不作自动展开或转换。空证据集合可以通过结构校验，但不会产生验收结论。

类型错误抛出 `TypeError`；非法 UUID 值或文本抛出 `ValueError`；结构、引用或关系约束错误抛出 `IdentityRelationError`，其为 `ValueError` 子类。失败不生成修复后的关系或默认状态。

## 4. IoC 与暴露方式

`vet3d.identity` 通过 `__init__.py` 提供公共导出。后续消费者直接使用具体稳定类型和同步校验，不为其增加镜像 Protocol、服务定位器或配置开关。包内不实例化数据库、供应商客户端、解释器或日志处理器。

调用边界负责提供 UUID 和关联输入；本项不把运行环境、readiness、部署版本或请求传输配置加入业务身份。没有新增 LLM Tool、Skill、CLI、HTTP 路由或宿主守护进程。

本包按 L0-01 已有构建方式交付，并保持类型信息对外部消费者可见。Demo 的装配和文本回显不引用新身份，也不增加无实际用途的身份字段。

## 5. 正常流程与副作用

1. 调用方提供 UUID4 值并构造相应身份对象。
2. 调用方以明确的身份类别构造关系及目标，保持本项所需的归属和引用。
3. 同步校验核对该次输入的身份和关系，成功返回 `None` 或抛出已定义错误。
4. 调用方在当前校验通过后决定是否交给后续服务；本包不自动发布、存储或执行任何业务动作。

本项没有文件写入、网络请求、后台任务、数据库事务或日志存储。校验不会改写输入、补造实体或修复冲突；不存在“关系校验完成即业务完成”的隐式转换。

## 6. 失败、取消与恢复

| 情形 | 本项边界 |
| --- | --- |
| UUID 值或身份类别无效 | 拒绝错误输入，不自动生成替代身份，不将其他概念的 ID 隐式转换为当前身份。 |
| 归属、引用或目标关系无效 | 由对应局部校验入口抛出 `IdentityRelationError`；不从其他工作区、显示名或路径猜测目标，不确认未提供的祖先关系。 |
| 证据集合为空或没有已知来源边 | 按本项关联规则处理；不能补造验收通过、原件或未执行结论。 |
| 调用中断、进程退出或重启 | 没有本项拥有的持久状态、恢复句柄或在途外部请求。重新校验是对新提供输入的一次校验，不是恢复旧执行。 |
| 同时进行多次校验 | 各自使用调用方输入，本项不持有可变全局关系库；不提供存储层并发、锁或唯一约束保证。 |
| 文件写入、报告、远端提交或回执不明 | 不适用；本项没有这些副作用及其状态。不能从校验通过推导它们已完成。 |
| 关系有效但业务验收不足或失败 | 本项不作质量判定；保留身份和关联语义，由后续验收规则及状态条目处理。 |

本项为纯同步调用，不添加异步取消端口或超时配置。外层是否取消调用由宿主处理；身份检查不能替代执行层的取消、重试与恢复。
