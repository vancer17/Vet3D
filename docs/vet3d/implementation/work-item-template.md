# 实施工作条目模板

本模板用于将[分层实施清单](layers.md)中的一个具名条目展开为可开发、可验收的工作包。条目 ID 沿用 `Lx-xx`；需要进一步拆分时使用子 ID 并保留父条目，避免重编号使已有引用失效。Vet3D 业务接口和状态由实际消费者决定；原生运行时工具、会话与反馈优先沿用其接口，不将 Hi3D 原字段当成已实施的 Vet3D 接口。

[实施总纲](README.md) · [分层条目](layers.md)

## 使用与完成规则

- 只为进入当前阶段的条目建立实施卡；卡片文件位置可在落地时确定，并由分层清单引用。
- 一项条目须能明确说明输入、输出、权威状态、依赖与失败恢复。仅内部实现函数通常作为步骤维护。
- 上游依赖引用具名条目和契约版本；前置项使用替身时显式记录，真实集成验收仍是未完成。
- 技术栈、供应商或接口待定时记录阻断范围和最迟决策点，不虚构已选 API。
- 完成卡片时回填实现出处及实际验证结果，再更新分层清单和阶段状态。Hi3D 证据或本卡写成文档不能替代 Vet3D 验收。

状态使用 **未实施、实施中、待验收、已完成、受阻**。受阻时记录具体依赖及解除条件；只要本条目必需的实现、真实依赖验证或验收仍有缺口，就不能标为已完成。可将当期支持范围单独成条目，其余扩展保留独立状态。

以下为实施卡的正文模板。字段中的“待填写”是模板占位，不表示设计或实现已经完成。

## 1. 身份与范围

| 字段 | 填写内容 |
| --- | --- |
| 条目 ID、名称、架构层 | 待填写，引用所属 `Lx-xx`。 |
| 当前状态、所属里程碑 | 初始未实施；填写 M0～M4 或后续增量。 |
| 开发优先级 | 首期闭环／首批业务／条件扩展。与 P0／P1 归档标签分开。 |
| 目标与用户可观察结果 | 待填写，描述本项完成后上层能做什么。 |
| 本期支持范围与边界 | 待填写，列明平台、输入类型和实际支持能力。 |
| 交付物 | 待填写，接口、实现模块、Tool 说明、资源清单、验证和使用入口。 |
| 参考采纳方式 | 借鉴机制／独立实现／评估接入／暂缓。 |

## 2. 前置依赖与上层消费者

| 字段 | 填写内容 |
| --- | --- |
| 前置条目与必需能力 | 待填写到具体条目、端口及契约版本。 |
| 上层消费者 | 待填写具体服务、上下文、Tool、节点或宿主。 |
| 接口所有者 | 稳定内核或消费方；写明选择原因。 |
| 使用的真实／替身实现 | 待填写，分别标记集成完成与待验证范围。 |
| 可并行实施部分 | 待填写，说明共同契约固定后哪些实现不互相阻塞。 |
| 待决策与解除条件 | 待填写，记录决策最迟点及影响范围。 |

## 3. 输入、输出与权威状态

| 字段 | 填写内容 |
| --- | --- |
| 触发者与触发条件 | 宿主、业务节点、编排器、LLM Tool 或本地执行调用方。 |
| 输入语义 | 必填、可选、默认值、文件角色、工作区／会话／轮次范围和参数约束。 |
| 输出语义 | 返回值、文件清单、摘要、版本、状态及未覆盖项。 |
| 身份关联 | 工作区、任务、调用、尝试、远端作业、产物、验收记录及加载代次中适用的关联。 |
| 权威状态源 | 谁持久化事实，谁只提供快照；事件与磁盘不一致时如何对账。 |
| 可复用条件 | 仅在存在结果复用消费者时填写其业务依据、失效条件和已有证据；原生工具接续不要求执行内容冻结或字节追溯。 |
| 上下游交接 | 下游取得什么，核对哪些权限、业务事实或正式产物；不把所有内部文件操作升级为正式交接。 |

涉及参考图片时分别记录主体基准、操作主图、补充参考、目标方向和必保特征；实际传输槽位由适配器映射。涉及模型时分别记录文件、模型版本、验收与视窗加载身份。缺少某种证据时使用明确的未知或待核查状态。

## 4. IoC 与暴露方式

| 字段 | 填写内容 |
| --- | --- |
| 实现的接口、注入的端口 | 待填写；上层不自行实例化具体数据库、供应商 SDK 或执行器。 |
| 装配入口 | 待填写真实与测试装配如何选择实现和配置。 |
| 宿主／内部服务入口 | 待填写，不默认对 LLM 开放。 |
| LLM Tool 入口 | 区分原生工具的配置／验证与 Vet3D 领域工具的新增接入；仅对实际自有工具填写注册与独立文档。 |
| Skill／资源入口 | 说明发现、选用及实际执行条件；Skill、脚本、库函数和工具枚举分别标记。 |
| 权限与配置范围 | 允许读写位置、可执行能力、交互需求及有效环境，按实际产品配置定义。 |

自有 Tool 文档维护模型可见 description、参数和实现。原生工具引用运行时依据，记录必要适配差异，不复制工具路由或反馈循环。实施卡和业务节点引用工具页并解释适用条件；工具页不反向绑定本卡或业务节点。

| 步骤 | 输入与分支 | 状态及文件变化 | 可观察输出 |
| --- | --- | --- | --- |
| 待填写 | 待填写 | 待填写 | 待填写 |

需要示例时注明 **Vet3D 设计示例、实现伪代码、源码摘录或已验证行为重建**。路径用于追溯，不能代替对分支和结果的自然语言说明。

## 6. 失败、取消与恢复

逐项填写适用分支；不适用时写明原因。

| 情形 | 必须明确的行为 |
| --- | --- |
| 参数、能力或作用域无效 | 是否已产生副作用，如何修正，是否允许重用原意图。 |
| 本地进程仍运行 | 原句柄如何续读、取消和取得终态；新进程不是原进程续接。 |
| 远端 pending | 如何按原作业续查，查询预算与终态如何记录。 |
| 提交或回执不明 | 保存哪些原始关联，如何核对受理；幂等保证来自哪里，没有保证时如何阻止盲目重交。 |
| 文件已写、登记或报告失败 | 哪些工作文件、部分文件或候选可能存在；正式产物按其身份与完整性契约对账，普通工作文件按原生会话及实际现场继续。 |
| 写入中断、同址与并发 | 临时文件、替换、锁、覆盖规则及不同文件之间的事务边界。 |
| 用户取消、进程退出或宿主重启 | 是否仍有后台任务、如何恢复身份、是否保留原件及候选。 |
| 结果可用但业务验收未过 | 保留候选与失败依据，如何继续修订、旧结论何时失效；仅适用的业务执行契约使用新 Attempt，不为每次编辑或预览创建业务尝试。 |
| 状态、版本或加载回调过期 | 如何识别并拒绝迟到结果，如何刷新当前事实。 |

完成进程、产出文件、写出报告、内容验收、版本发布、视窗就绪和外部保存分别判定。不存在统一质量结论时，不给输出补造 `pass`。

| 检查项 | 方法与夹具 | 预期结果 | 实际证据与结论 |
| --- | --- | --- | --- |
| 正常输入与输出 | 待填写 | 待填写 | 未执行 |
| 跨工作区／版本身份 | 待填写 | 待填写 | 未执行 |
| 适用失败及部分落盘 | 待填写 | 待填写 | 未执行 |
| 取消／中断／恢复 | 待填写 | 待填写 | 未执行 |
| 上层契约与真实依赖集成 | 待填写 | 待填写 | 未执行 |
| 业务质量或目标动物 | 适用时填写样本、用途和覆盖范围 | 待填写 | 未执行或明确不属于本条目 |

优先验证对上层有影响的契约和失败边界。纯文档、低影响可逆修改按实际需要检查；不为复述实现内部步骤编写无意义测试。实际模型、宿主或动物样本未验证的范围单列，不扩大合成夹具结论。

涉及运行时接入时，按 [L2-02](work-items/L2-02.md)先取得小型自主任务及原生代码、日志、图像反馈的真实证据，再决定后续接入；失败也如实形成决策依据，不据此扩展实验为领域质量或自动返工体系。

## 8. 完成与上层放行

- 本期范围内接口和实现已交付，模块依赖与注入符合所在层的约束。
- 适用业务关联、权威状态源与副作用明确，错误和恢复已验证；不要求逐次原生工具的精确执行内容复现。
- 使用的资源、执行环境和适配器版本可定位；真实依赖与替身证据分别记录。
- 必需的上层集成检查通过；未覆盖扩展有独立条目和状态。
- 独立 Tool／资源说明、实施卡引用及阶段导航已核对；不引入反向节点引用。
- 回填实现出处、验证记录、待实测范围及上层可开始的条目。

## 9. 证据与变更

| 类型 | 填写内容 |
| --- | --- |
| Hi3D 参考 | 固定版本文档或安装包出处、已核实行为及本项采用的机制。 |
| Vet3D 设计决定 | 选择、原因、被约束的契约和待定项；不能标成 Hi3D 原有行为。 |
| Vet3D 实现 | 实际模块／提交及有效配置，未实现时保持空缺说明。 |
| 验证记录 | 环境、版本、适用业务身份或原生调用记录、预期及实际结果；记录粒度不扩展为执行内容追溯。 |
| 质量覆盖 | 隔离夹具、真实供应商及目标动物各自的覆盖范围。 |
| 变更影响 | 契约、资源或实现变化后需重新验收的条目与上层结论。 |
