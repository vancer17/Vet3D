# 粗模、空间校正与遮挡分割

## 1. 先确定要还原的物体

读取全部用户输入：同款、同一状态的多角度照片可共同约束；不同涂装、版本、打开/关闭状态或不同姿势分别标记。冲突时以用户指定主图决定最终身份和姿态，用其他图补充局部结构。低清或遮挡区域保留不确定性，不因多图数量多就平均成混合物体。

记录轮廓、部件连接层级、相对尺寸、材料区域和明显非对称特征。区分可见表面与整件体积。用户只给单图时，先使用其中可见的侧面厚度、斜向透视和遮挡次序，再求助同款参考。

每条结构结论从这里开始带上来源，后面的环绕关卡只复核几何，不改写来源：

- `observed`：该边界、厚度、前后或连接位置能指到参考图里的可见区域，或指到已记录的补充参考。
- `inferred`：参考里看不见，靠体块连续、同款线索或设计假设补上。补充参考覆盖到该区域后，把这一条改为 `observed` 并写下路径和范围。

没有来源标记的结构不能进入四视图或高模提交。

## 2. 建立语义部件与邻接图

按可独立生成、合理接缝、装入路径和外观连续性选择边界。一个颜色块不必是一件，纹饰、装甲和主体也不必逐层拆。优先完整结构单位：例如家具座面、桌腿、灯座/灯臂/灯罩，车辆车身/轮组，器物主体/盖/把手；选择依实际图片与装配目的。

每件对应可解释的闭合体块、局部框架与连接候选区。大量相同部件用唯一形状+实例记录；不能把动物四条腿或家具四条腿都当作严格镜像。环形框架、多点把手、左右贯通轴需要预先记录多条邻接边和可能的装配闭环。

简化原则：粗模只提供尺度、朝向、深度和部件相对位置的初值。长方体、圆柱、球、楔体及简单截面足够；保留一体外壳，不建细小装饰。避免把照片轮廓挤出成薄板，尤其是倾斜、前后叠放和旋转部件。

## 3. 三维自校正

在 Blender 中由参数构建粗模，保存后渲染前、后、左、右、上、下及有诊断价值的斜视。对于底面不可见、对称的物体，可记录对应检查为何没有新增约束；不能仅保留前图。

每轮执行：

1. 在原图相机近似下叠加粗模，比较身份特征、主要比例和遮挡关系。控制镜头与物体位姿分工，避免用镜头掩盖结构偏差。
2. 切换正侧/顶视检查厚度、前后层级、轴线、接触区域和支撑面。物体的天然空腔、轮廓间隙和附件前后位置应存在。
3. 逐件修改三维中心、局部轴与尺寸，优先改导致多视角同时错误的自由度。仅以自己的种子标点计算低投影误差不是独立验证。
4. 检查邻接件能在参考姿态下合理承接；存在位于中间的真实硬件时保留空间。粗模少量已标记的邻接重叠可作为包络，不能直接当成最终接口。
5. 重新渲染受影响方向，再看整体，直到没有已知明显错位。单图隐藏深度仍应标为推断，不声称凭查看恢复了唯一真实形状。

完成时提供实际粗模、每件尺寸和矩阵、邻接图、渲染与审查。执行者自行校正；只有身份不可判定或互相冲突的目标才需要用户澄清，常规位置选择不转嫁人工校准。

正交与斜视校正通过只说明初始空间支架可用，还要完成下面的生成前环绕关卡才进入付费生成。这一步不锁定高模最终坐标。高模回装后必须按[配准规则](registration.md)重新做视觉与承接校正；实际部件的厚度、轮廓和连接端可能与体块不同。

## 生成前环绕关卡

第 3 节的正交、顶底和斜视渲染继续保存，用来对照原图。它们不是进入逐件高模的关卡。关卡对象是已经保存、可在 Blender 中打开的粗模工程和部件树。执行者要实际旋转视角，而不是只播放预先列出的几个相机。

通过前须完成：

1. 从任意角度旋转粗模，检查部件边界、厚度、前后关系和连接位置。固定清单里没有的角度，只要会露出叠放、斜接或细杆，就要转到。
2. 在整体与单件之间切换。单件用来看该件自己的体块和局部轴；整体用来看它在装配里的位置。
3. 隐藏挡住目标的邻件，再看被挡住的接缝和厚度。藏住遮挡件仍看不清时，记下是结构问题还是参考里本来就没有这一面。
4. 把发现的错边、成片、前后反了或连接落点不对写回粗模，改完再转一圈。已知结构问题未关闭时，关卡不通过。

两类结论分开写进同一份记录，不能互相充当证据：

- **结构**：环绕是否发现边界、厚度、前后或连接位置的问题，以及改完后的工程路径、当时的可见集（整体、单件，或隐藏了哪些件）。
- **来源**：每条结构仍是 `observed` 或 `inferred`。环绕能否定一个不合理的体块，不能证明参考图里看不见的背面、内腔或完全被挡住的连接件长什么样。那些区域保持 `inferred`，直到补充参考覆盖后改为 `observed`；用户允许推断时，也可以保持 `inferred` 进入后续阶段，但四视图和高模记录里要继续带着这个标记。

生成前关卡未通过时，不把推断面做成待提交的四视图，也不调用 Hi3D 逐件生成。无结构依赖的视图草稿可以准备，但不能送去付费生成。此关卡是执行者的观察出口，不新增逐件用户批准；身份无法判定时仍按第 3 节询问用户。

已有合格高模、不再重建粗模时，用现有网格的装配占位做同一次环绕，见[整模拆件](existing-sculpture.md)。跳过付费生成不跳过这道关卡。

## 4. 用粗模帮助拆分原图

在匹配每张源图的相机下渲染部件 ID、深度及轮廓，形成语义投影。结合照片中的真实边界修正投影：粗模提供归属先验，不直接硬裁所有像素。

为每件保存两种范围：`visible_mask` 是图片中该件真正可见的像素；`amodal_extent` 是估计的完整部件范围。完整范围内被其他件遮挡的像素不能作为目标件外观输入。保留原图裁片、遮挡者 ID、完整粗模单件参考及邻接背景图，用来生成完整部件。

部件分离时补全被遮住的连续体积，保持边界附近已观测的颜色、厚度和结构；让生成器去掉邻接件而保留接合处材料。裁出小块可见表面后直接生成，容易丢失深度、误带相邻结构或在拼接处缺肉。

Hi3D 云端拆件可作已有网格的辅助候选，前提是已核对当前接口适用于该类别。它不代替代理定义语义边界与校正；API未明确支持的手动点、mask、切面约束不能假称受支持。已有独立粗模部件通常无需再调用收费拆件服务。
