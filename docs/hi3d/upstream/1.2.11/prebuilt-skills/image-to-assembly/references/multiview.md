# 部件四视图与外观一致性

文生图/图生图调用失败时停止该失败调用的自动重试并报告原因，保留原任务与已有产物；用户明确要求后才重试或恢复。调用成功但效果不佳时，按本流程和已有授权继续定向修图或重新生成，不因质量未通过新增逐轮确认或暂停整项任务；质量修订次数和最终验收门槛仍按原规则执行。正常 pending 继续查询原任务，不重提；不依赖失败结果的阶段可继续。

## 证据优先级

用户原图中的清晰可见区域最高；同款同版本官方/清晰实拍补充侧背；同系列近款只提供结构线索；最后才是明确标注的生成推断。检索与下载参考应记录页面 URL、对应图、版本判断和用途。不能让相似商品替换原图的比例、配色、标识或连接方式。

默认为每个唯一部件补全前、后、左、右四视图，充分利用源图的斜视信息。原图一张不等于只能生成一面；多张原图也不意味着每张都直接上传。先统一身份和姿态，再综合为同一部件四个标准方向。隐藏面缺乏确证时标为 `inferred` 并给出低置信度，但继续在用户允许的推断范围内完成。

四视图可以在粗模仍在修订时起草。把推断面提交为高模输入之前，[生成前环绕关卡](proxy-segmentation.md#生成前环绕关卡)必须已经通过。环绕里看到的粗模背面不是参考证据：视图上的隐藏面仍按 `observed` 或 `inferred` 标记，不能因为粗模已经转过一圈就写成实拍。

若用户明确限制“仅原图/仅观测方向”，遵守限制：只有已可靠还原的方向进入对应 API 槽位，其余让 Hi3D 补全并说明局限。调用最多四图，不能把额外顶/底图塞成错误的左/右图；顶/底信息融入侧面的几何描述和检查，必要时保留为后处理参考。

## 一套部件规范约束四张图

生图前读[视图定义](view-conventions.md)，从共享相机表生成参考图，并将实际画面朝向绑定到API槽位。官网UI标签与API侧槽存在交换关系，不能仅用“左/右”或文件名传递方向。

先建立共享规范：该件包含什么、排除什么，局部前后左右，主轴与尺寸比例，层级与共有地标，材质/颜色/磨损强度，保护外观区、连接预留区。统一场景光照与中性背景，避免阴影被模型当成凹坑。

选择证据最强的一面作基准，建立有证据的相反面，再让侧面同时参考主图、粗模体块及前后基准。每次给图像工具明确哪些图控制身份、哪些仅控制几何，避免多张参考互相抢主导。四张最终图片是独立无标签单件图片；对照拼图仅供审查，不能作为一次“多视图”输入。

各图正对相应方向，尽量正交：侧面不能仍展示大片正面；透视图不可通过文件命名冒充正交图。同一部件维持共同高度、尺度与上下位置，画布比例和留白一致且不裁掉附件；深度与正面宽度自然不同，无需强行把每幅横向宽度归一。

提示词可用 [模板](../assets/view-prompts.md)，根据对象填写具体结构，不把人形身体术语套到产品上。执行环境要求先查看参考图时，先看图再编辑；按环境的图像工具规范传入真实路径。

## 加工预留是材料区域

依据邻接图，在将来插杆根部、母窝孔口和周边留下宽阔、连续、低细节的可加工区域。用粗模尺寸做初始体积预算：横向应覆盖销/孔半径、局部壁厚与定位余量，纵向应覆盖根部或窝的实际深度与底部材料。工艺未知时用暂定比例并记录，不能把数值称为制造公差。

预留尽量向原外壳内部布置，保护外形和原图的间隙/可见硬件。小圆点、装饰性凹圈、外凸盒并不代表足够材料。此阶段不要求精密孔、螺纹或连杆；生成真实高模后才测量材料并加工。几张图看起来平整不能证明内部实心。

## 审查与修复

生成后实际查看每幅图和对照拼图，记录下列检查：

| 检查 | 拒绝/修订条件 |
|---|---|
| 身份与范围 | 多了相邻件、漏了应一体的结构、混入其他版本 |
| 方向与尺度 | 左右命名混乱、侧图斜视、上下漂移、同一层级比例变化 |
| 结构对应 | 前后同高度层在侧图不相接，端口/支座中心在各图矛盾 |
| 材质一致性 | 装配后像不同套物品，金属/涂漆/磨损强度不一致 |
| 隐藏面 | 有同款证据却重复前面独有特征，或把推断当实拍 |
| 预留 | 平整面太小、内部体量不足的明显趋势、为补料改变可见轮廓 |
| 对称与非对称 | 配对标准结构漂移，文字反转，非对称附件被抹掉 |

同一地标用归一化坐标比较；跨图共同高度和材料边界应一致。尺寸/地标允许误差由当前尺度及可见分辨率提前定义，审查记录实测与依据，不靠“相似度高”统一放行。图像对位仍不能称为严格几何标定。

原图文字清晰时，逐项记录实际字符、所在物面、朝向及版式；生成结果虽可读但字符改变，仍属身份不一致。原字不可辨认时标为未知，不编造读法。高模几何正确而文字/标识错误时，优先从用户原图恢复局部贴花或纹理并检查投影、UV与朝向，保护周围材质；无需为这类局部纹理问题重新付费生成整个部件。此检查同时适用于派生图片与最终高模。

只修最早造成矛盾的图，明确“修改区域”和“保护区域”，再回看整图及其他方向。局部改肩侧曾误改背包/背甲，因此不能只检查被编辑的小区域。同一部件的依赖编辑按版本串行，避免引用并发产生的错版图。跨部件允许独立推进，但使用共同风格与身份基准。

重复的格栅/窗户是否错误必须看证据：没有背面参考时记录为推断，不凭“重复”定错；有真实背面时依其纠正。单件接缝尚未统一通常不阻塞其余部件生成，错误身份、矛盾视角与严重缺失应在收费提交前解决。
