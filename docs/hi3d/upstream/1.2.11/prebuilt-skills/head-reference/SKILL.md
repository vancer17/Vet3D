# 头部参考图

一个图像原子能力，四视图按基准姿态分为两种模式，不是两套重复 workflow。裁切/颈部、背景、造型与材料是共用参数；单图处理仍可独立调用，不是必须先走的档位，也不是 head → front → four-views 的执行链。用 `$head-reference` 或显式读取本入口，提供原图、输出目标、姿态模式及包外目录。只要提示词时不擅自生图。

| 分支 | 从原图直接执行的目标 | 交付 |
| --- | --- | --- |
| `head` | 去除背景主体之外的肩胸、身体及底座，保留完整头部和头发；保持原姿态 | 一张头部参考图 |
| `front` | 保留完整头部并将 yaw/pitch/roll 转正；不读取 head 分支作为必需前置，不顺带改表情 | 一张正面头部图 |
| `four-views` + `pose_mode=aligned` | 先建立标准正面，再补鼻尖朝画面右、后、朝画面左 | 四格 `front,right,back,left` 与语义 manifest |
| `four-views` + `pose_mode=current` | 基准保留原图左右朝向、抬头/低头及侧倾；固定该头部姿态，仅换观察方向 | 相对视图 `view_0,view_90,view_180,view_270` 与语义 manifest |

新四视图任务明确选择 pose_mode；旧 manifest 缺省姿态仍按 aligned 解析，但左右命名不自动迁移。aligned 使用画面鼻尖方向命名（朝右 right、朝左 left），manifest 必须声明 `view_convention=screen-nose-direction-v1`；缺失或旧约定须核对实际图像、另存正确对应关系并重审，不能仅补字段。current 的 view_0 不等于正面，其余角度为相对环绕目标，不是从照片测得的精确相机参数，也不套用 aligned 鼻尖方向标签。单图 head 固定 current，front 固定 aligned，不能传入相互冲突的模式。

头部包含头发、眉毛、耳朵及原有头部饰品；不是去发光头。保留原发长，不用截短长发满足“只留头部”。颈部范围沿用用户或调用方约定；未指定时可保留自然短颈，但不得留下肩胸衣服。背景采用干净中性底，不将“去背景”擅自解释为必须透明 PNG。

用户或调用方明确要求局部去除（例如头雕去悬空刘海）时，该范围优先于通用“保留全部头发/发梢”；只修改指定部分，保留其余发型与发际线，并在所有视角保持一致。没有这类要求时不自行删刘海。

## 执行与复用

先看输入和已有产物，再读 [提示词与视角验收](references/prompts.md)。每个所选输出从原图独立开始；同时要求多种对照时不默认串用另一模式的产物。四视图内部先验收自己的基准：aligned 是标准正面，current 是原姿态 view_0；current 不先过一次转正。只有明确要求复用已有合格图时才续接，记录真实来源与模式；已有合格四视图只检查整理，不为补阶段文件重生成。

使用宿主已提供、且符合用户选择的图像编辑能力；遵守其查看/引用图片规则。不内置模型、API 客户端或服务名，不因为此 skill 被调用就更换用户指定的生图工具。工具缺失时可交付提示词及缺失项，不把提示词当作已经生成的图。

通用调用未指定造型/材料时保留输入的自然色彩、皮肤年龄特征和发型，不自动树脂化、灰化、去皱或去除虹膜。调用方的必选造型约束与可选材质分开传递：例如可打印头雕传入的实体发束约束，必须附在 head、front 和 four-views 的每次生成/修订中，不能仅放进四视图或可选材质块。默认外观只能保留不与该约束冲突的特征。材质改变不改变视角；图像中合成的后脑/侧面只能标为推定，不当作真实扫描证据。

## 完成与交接

输出实际图片、实际使用的提示词及 manifest，保留原图、分支及实际生成输入、必选造型约束、颈部范围、风格选择、各图语义视角、裁切/pad、尺寸、复用关系与逐项检查结论。图片保持比例，提交方形输入前只补边、不拉伸。四格拼图必须拆出完整视图并逐图检查；不能把整张拼图作为一张 front 交付。

只将通过身份、头发完整性及必选质感、姿态与视角一致性检查的结果标为合格；失败/不确定可展示但不得通过。front 与 aligned 的正面分别检查 yaw/pitch/roll 是否转正；current 则逐项对照原图是否保留朝向、俯仰及侧倾，整组是否同一个固定姿态，不套正面零度目标。图像须实际查看并记录依据，不能以文件存在、prompt 或工具成功代替。调用成功但质量不合格时保留版本，按已有授权针对修订；同问题连续两次修订仍失败交回用户选择。调用失败则停止自动重试并报告，用户明确要求后才重试或恢复。只要图像时结束，不自动建模/修鼻/贴图/分割。图像评审通过不代表下游服务支持该视角格式；current 不改名为标准 front/back/left/right，调用方须确认适配。

评审在本能力内部执行：读取 [评审契约](references/review.md)，用 `scripts/reference_review.py prepare/check` 生成完整必查矩阵、版本绑定和可选 HTML 报告；实际看图者填写逐项证据，调用方追加品类策略。漏项、旧图/旧 prompt、失败或未检查不能放行；当前仍需真实人工确认，不把未校准评分当自动检测。源码、策略与例图变化同样使旧评审失效。该脚本不生图、不执行重试、不建模，也不另起服务。

需要独立分发时按 [打包约定](../.dependency-package-tools/references/usage.md) 提供完整目录；评审脚本仅依赖 Python 标准库，不依赖作者机器路径。阶段和产物定义见 [architecture](pcg/architecture.yaml)，检查点见 [routes](pcg/routes.yaml)；实际运行产物放在包外。
