# Low-poly 四边面与面颈校准

## 宿主执行模式

在 desktop 中先读 [Runtime 执行约定](../.dependency-run-tools/references/desktop-runtime.md)。本入口不重新生成低模或高模；已有网格在本地 Blender 中处理。加载本入口后把 [宿主编排提示](../.dependency-pcg-view/references/host-orchestration.md) 注入编排 agent。

## 独立工作流与依赖

执行 lowpoly-quad-face-neck 前，按 [打包约定](../.dependency-package-tools/references/usage.md) 和 [依赖清单](package.json) 在仓库外生成完整分发目录。本包没有可执行造型脚本，四边面、面颈与烘焙由执行者在 Blender 中按引用资料完成；分发时保留文档与示意图布局。[统一计时规则](../.dependency-run-tools/references/stage-records.md) 与下文阶段一起使用；已有合格四边面、区域或贴图可从对应阶段继续。

以用户认可的现有 low-poly 作为拓扑和轮廓起点，以同主体、同姿态或能够可靠对齐的高模作为几何校准参考与纹理烘焙源。优先复用已完成的四边面、UV、材质和对齐结果。识别到脸部后，面部—下巴—颈部是必须闭合验收的局部阶段，不允许只细化五官后结束。无脸时跳过面颈专属阶段，仍完成整体连接与交付检查。

本入口不生成高模。缺少低模时只交接已有的风格化低模流程，不在这里另写减面。网格闭合不代替完整打印验证。

## 输入门槛

进入对齐之前，先清点当前对话里的 GLB：用户给出的文件、本会话已登记或已导出的模型，以及任务目录里按 [对话产物引用](../.dependency-run-tools/references/artifact-refs.md) 能解析到的网格。没有 GLB 就停止，说明缺高模，不开始四边面。

高模是硬条件。至少要有一份高模 GLB，三角面数约在两百万量级；用 [mesh-audit](../.dependency-mesh-audit/REFERENCE.md) 的 `measure_mesh` 读取三角面数。这个量级用来认出高模，不是必须等于 2000000 的通过线。只有数万或数十万面的结果不能充当高模。对话里有多份高模时，用用户指定的那一份；主体不明就先确认，不擅自换模。没有合格高模时停止，不调用生模。

低模可以已经在对话里。没有可用低模时，用已确认的高模交接 [connected-faceted-lowpoly](../connected-faceted-lowpoly/SKILL.md)（风格化低模），取回它交付的低模后再继续；已有合格低模不调用。对照工程里隐藏的原模仍是高模，不能把它当成低模。低模 GLB 可以读入，但不能用它的三角面数否定已有工程里的四边面。

## 输入与完成结果

以 `$lowpoly-quad-face-neck` 或显式读取本文件调用。门槛未满足时不进入下表的制作。

| 输入 | 输出 |
| --- | --- |
| 当前 low-poly（对话已有，或由 connected-faceted-lowpoly 刚交付；BLEND/OBJ 优先） | 可编辑 BLEND：真实四边面、命名环线/区域、纹理；高模与修改前对照可隐藏保留 |
| 同主体且可对齐的高模 GLB，三角面约两百万量级，以及真实材质/贴图 | 不三角化的 OBJ+MTL+贴图包；GLB 预览含 `sparc3dPhysicalUnits = {version: 1, unit: "meter"}` |
| 可选：已有 UV、配准矩阵、布线参考、面数或误差约束 | 分区域检查报告、选边说明，以及同视角贴图/无贴图/线框对照（须能看见下巴底面和颈侧） |

高模无贴图时，保留已完成的几何工作并收集缺失纹理源，不把参考图片投色冒充高模烘焙。

成功时：

1. 目标重建区与各衔接带为真实四边面；要求整模全四边面时，整模统计也为四边面。顶点重合不等于拓扑连接。
2. 有脸时，眼眶与嘴唇有可连续选择的闭合环线；下巴覆盖唇颏沟、颏尖、下颌缘与颏下转折；现有颈部有轴向边链和截面环线，并与冻结区以四边面相接。
3. 形状按对应高模语义表面校准。贴图来自高模烘焙；已认可身体纹理保持，过渡带只修接边颜色。
4. 导出、登记、视窗加载三种状态分开记录。只有导出文件时不声称宿主交付完成。

## 执行顺序

先读 [方法与实现](references/method.md)，执行时使用 [验收与恢复](references/acceptance.md)。[来源与验证范围](references/evidence.md) 区分已验证方法和尚未在来源案例跑通的面颈规范；案例参数不是模板。可参考 [面部边流示意](assets/hi3d-face-edgeflow-reference.jpg)，学习围绕五官的流向，不替换目标脸型，不照搬孔洞或固定面数。

PCG 路径：`main` 从对齐做到交付；`no_face` 在确认无脸后跳过面颈专属阶段；`from_face` 在四边面已合格时从区域提取继续；`rebake` 在几何已合格时只烘焙并交付。

1. **inspect_align**：只在高模已经确认、低模已经在手时开始。核对模型家族、最新版本、主体、姿态、坐标轴和尺寸。必要时用语义锚点初始化配准，再做有约束的表面拟合。不可靠时停止依赖它的投射与烘焙。划定冻结区、重建区和过渡带。
2. **quad_base**：已有合格四边面直接复用。三角低模按邻接、转折、形状与语义做配对或相容四边格，保留主要姿态和块面。不跨薄片、独立部件或应保留边界盲目焊接。
3. **face_neck_regions**：结合多视图和网格空间关系识别人脸或拟人脸。有脸时先提取额头、五官、颏部、左右下颌、颏下转折、颈前、颈侧/颈后和颈根。先提取下巴块面，再进入校准。明确无脸才跳过本阶段及下一步。
4. **face_neck_retopology**：围绕眼、口建立闭合四边环线，按实际鼻型组织鼻梁与鼻翼，把边流延续到下巴和现有颈部。新顶点投射到对应高模语义表面；下巴底面、颈侧和颈后分开取方向。
5. **quad_transition**：新区域与旧网格共享边界顶点和边。面部到下巴、下巴到颈部、颈部到颈根，以及重建区到冻结区，都必须是真实四边面。奇数边界不靠三角面补洞。
6. **bake**：形状和连接合格后再烘焙。颜色烘焙调用 [texture-bake](../.dependency-texture-bake/REFERENCE.md) 的 `bake_image`；法线仅在任务需要且源数据可信时使用同一入口。分区 cage 与旧贴图接边融合由本流程按方法文件完成，不把融合算成烘焙函数已完成的事。
7. **validate_deliver**：连通、边界边、非流形边和退化面调用 [mesh-audit](../.dependency-mesh-audit/REFERENCE.md) 的 `measure_mesh`。四边面角数、命名边链和语义区域覆盖按验收文件另计，不用三角化后的边数代替原多边形。按 [宿主交付工具契约](references/host-delivery.md) 区分导出、`workspace_commit_model` 登记和 `studio_load_revision` 加载。

后台打开、导入、另存和预览渲染交接 [blender-tools](../.dependency-blender-tools/REFERENCE.md)，不另写 Blender 启动器。来源高度归一化与整模焊接不交给会合并全部网格的准备流程；本流程要保留部件、冻结区和有意边界。

阶段记录遵从 [run-tools](../.dependency-run-tools/references/stage-records.md)，由执行者把真实起止、状态和耗时写到包外任务目录。本包没有自动计时脚本，token 无采集时标 unavailable。无脸分支对面颈专属阶段记录真实跳过原因。

## 本地长任务预算

三角配对、表面投射、四边衔接和离线烘焙可能长时间占用 CPU，且期间可以没有业务产物。进入这些步骤前，任务目录必须已有预算和心跳；后台 Blender 由 [run-tools](../.dependency-run-tools/references/budget-run.md) 的 `process_run.run_budgeted` 启动。建议低档 120 秒（单次回读或预览）、中档 600 秒（局部配对、投射或单次烘焙）、高档 1800 秒（整段四边面加面颈和多视角对照）。低档可直接跑；中高档由宿主 `waiting_choice` 使用本入口 `choices_example` 确认后再启动。超时记 `interrupted`，不写半截 BLEND、OBJ 或 GLB。加时只在用户确认后用新输出目录和新的 `max_wall_seconds` 再跑。

## 恢复与记录

对齐不可靠时保留已通过的基础拓扑，停止投射和烘焙。下巴或颈部漏选时回到区域提取。边界奇偶不兼容时只在授权过渡带改布线。检查通过后仅导出或登记失败时，保留工程，只补缺失交付步骤。宿主工具缺失时可以交付本地文件，但不把完整宿主交付标为完成。

来源案例验证了三角低模到全四边面、高模贴图烘焙和五官环线；完整下巴块面提取和环绕颈部校准是必须执行的规范，尚未在该案例中跑通。新实例须产出对应区域、几何和拓扑检查，否则只报告部分完成。迁入本仓库时未重跑该案例。
