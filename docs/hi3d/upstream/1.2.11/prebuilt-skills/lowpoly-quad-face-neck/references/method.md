# 方法与实现

本文件是执行指令。运行时根据实际对象编写本地处理脚本，不能依赖原对话的脚本、顶点索引、坐标、绝对路径或工作区文件名。

## 资产交接与可编辑性

接受上游提供的低模对象集合、原生工程路径、高模对象集合、坐标/单位、对齐矩阵、UV与材质映射及已认可区域。每次修改保存恢复点；从已有四边面继续时不再全身重拓扑。冻结区按顶点与面身份保存坐标、连接和每角 UV；不要只用数量相等验证未改变。

导入 GLB 后先区分逻辑网格边与 UV/法线分裂顶点。只有能确认属于同一表面接缝的重复顶点才可相容焊接。空间坐标相同但属于不同部件、薄片两侧或相交表面的顶点不自动合并。

## 低模三角面到四边面

1. 建立三角面邻接图。仅共享合法流形边的相邻三角面作为成对候选，检查合并后的四个唯一顶点及边界顺序。
2. 结合二面角、边长比例、内角、对边方向、凹折、原块面/材质语义和顶点价数评估候选。保护轮廓与重要转折；不是单纯删除每第二条对角线。
3. 在候选图上求互不冲突的面配对；要求完整配对时验证每个源三角面恰好被覆盖一次。求解时限到达不等于已有可用整数解，必须验证真实结果。通用图未必有满足全部约束的完美匹配，不能假设一定成功。
4. 若需要更规则且相容的四边格，对一组相邻面共享原边中点，增加每面中心，并用 `[原顶点, 当前边中点, 面中心, 前一边中点]` 构成四边面。共享点只创建一次。三角面也可由这一方式形成三个四边面，但邻面必须同步兼容，不能在局部留下 T 接点。
5. 面中心和允许调整的顶点投射回对应低模表面，保持整体块面起点。该步骤不保证原曲面误差为零，必须进行面内采样和轮廓对照。

本方法提升真实连通性和四边面比例，但全身存在极点，不能承诺一条边环穿过所有复杂交汇。已合格四边面直接复用，不为了统一方法重复细分。

## 先提取下巴，再校准面颈

### 语义锚点与区域

在对齐后的高模上以真实三维点记录：眉间、内外眼角、鼻根/鼻尖/鼻翼、口角/唇缘、下唇下方凹转折、颏尖、下颌左右转角、下颌下缘、颏下最低转折、颈前与颈后中心线、颈根接入位置。锚点不齐全时先利用其他视图定位，不由正面贴图颜色猜出不可见结构。

至少建立以下可追踪区域及其邻接：

- 五官与额头、脸颊；
- 唇颏沟至颏尖的前部块面；
- 颏尖到左右下颌缘的侧部块面；
- 下颌底面与颈前的转折带；
- 颈前、颈侧/颈后、颈根与旧躯干交界。

从上述锚点及局部法线/曲率脊线确定候选分区，再按网格邻接清理：移除头发、配饰和无关壳体，检查左右区域、底面与侧面的覆盖。曲率阈值随尺度和高模噪声调整；不能把法线噪声全部转成密集折线。高模分区完成后，将边界和区域身份转移到低模，并标出需要替换的面与固定外圈。

提取边界必须是拓扑合法的环或有明确端点的曲线。自动选区出现支叉或额外孔时，局部修整选区并记录；不能简单把最大的正面分量当作“完整面颈”。若下巴底面没有被选中，回到提取阶段，不继续只做正面校准。

### 五官环线

在眼眶、口周的现有可编辑区域建立围绕真实轮廓的多层环线，分别控制外部过渡、眼睑/唇缘与内部表面。鼻部按实际鼻梁、鼻翼与鼻尖转折组织，避免把任意鼻型固定成圆形环。

一种本线程验证过的局部做法是：取一个合法网格块的边界，向内部构造有序的轮廓环，以对应环上四个顶点形成环带；保留内侧表面时，将内环封成连续四边格。对于凸的平面参数域，可固定边界并对内部点做调和插值，再投到高模；非凸域不得假设这种方法无翻折。眼睛、嘴部原来有表面时，不因参考图画成空洞而删除它们。

环线必须随五官实际形状调整，不能将等距椭圆或长窄放射面作为通用完成品。检查内外眼角、口角、鼻翼与下唇是否仍然对应原高模，长窄过渡面需局部重新分配顶点和密度。

### 下巴—颈部边流

沿唇颏沟、颏尖突出、下颌缘和颏下转折布置边链，使正面与侧面转折都有真实几何支撑。让左右下颌边链经颏下过渡接向颈部，而不是把精细面部终止在嘴唇下方。

以高模颈部中心走向和若干实际截面组织四边环带。截面随颈部倾斜、转动和曲率变化，不使用恒定半径圆柱替代。纵向边流对应颈前、左右侧与颈后；颈根用相容过渡带接回冻结区。截面数量、每环顶点数和细化位置由几何与连接需求确定，不固定为案例面数。

## 分区投射与空间校准

面部正面可以建立局部右/上/前坐标架；它只是局部参数化工具，不可用于全部头颈表面。

- 五官正面：限制射线到对应高模面区，避免击中发丝、睫毛外层或后部表面。
- 下巴底面：采用底面法线或相应观察方向，并检查颏下到颈前的深度顺序。
- 颈侧/颈后：按环带的径向或可信表面法线投射，限制同侧候选与搜索距离。
- 多重命中、未命中、局部法线跳变或距离异常：标记待处理点，回到区域与候选过滤，不能无限延长射线或直接吸附到最近的其他表面。

允许在可靠邻点之间插值过渡带的深度，使新旧网格缓和衔接；它只能用于明确的接边区域，不能替代颏部/颈部主体的高模校准。投射后检查四边面的有向面积、弯折、局部自交与三角化显示下的折痕。保持所需块面感，必要时调整几何布局，而非仅更改法线。

## 全四边面衔接

新旧边界的顶点身份必须共享。先建立有序边界，再选择对应关系、环带密度与极点位置；不能独立生成两张重叠皮肤后当作缝合完成。

全四边面的圆盘区域要求外边界边数为偶数；更一般的多边界区域也要核对整体奇偶约束。奇数边界无法靠“补最后一个四边面”解决。需要时在允许的过渡带沿边条传播分割或调整选区，连同邻面一起保持四边面，不在冻结区制造悬空顶点。

同密度环带按 `[外环当前点, 外环下一点, 内环下一点, 内环当前点]` 连接。不同密度可用一层或多层极点过渡；仅在边界顺序、几何包容和朝向都满足时使用该方案。非平面边界需要三维验证，平面投影无交叉不代表三维无自交。

本线程的边界对应曾采用有序离散优化选择过渡分段，并逐面拒绝折叠/反向候选；不把其固定边数、矩形网格宽高或坐标复用到新模型。不存在合法对应时修改局部过渡设计，不能退回三角面补齐后声称全四边面。

## 烘焙与旧贴图融合

先冻结几何验收版，再准备 UV。五官优先减少跨眼睑/唇线的 UV 接缝；下颌底面及颈周应有适合其曲面的 UV 岛，防止正面平面 UV 折叠。按曲面面积和可见细节安排 texel 密度，颈部不能因沿用旧 atlas 而留下明显精度断层。

可建立临时烘焙接收网格及显式 cage，使投射方向与对应区域匹配。若原低模绕序朝内，先明确方向问题；临时接收网格和 cage 的法线方向要正确，不将它的翻转误写到冻结区。

先烘焙高模颜色，再按需要将原认可贴图投到同一个局部 UV。建立过渡权重：冻结边界侧取旧贴图，已校准内部取新高模贴图，环带中连续过渡。对线性色彩进行混合，保留 alpha 并做适当 padding。核对拼接处的色差、黑边、错位和穿透；确认烘焙只包含选定源与接收对象。

正文规定的下巴和颈部区域也必须被新烘焙或被证明确实可复用，不能只报告脸部图集清晰就忽略颏下和颈周。
