# 游戏角色资产交付

接收高模、已有 LOD 或已绑定工程，明确各 LOD 预算、目标身高、坐标朝向、骨架与动作范围、挂点和道具要求。该分支复用本包绑定/验收原子能力及独立 mdf-call，不提供一键任意角色游戏适配命令；引擎接入、物理和可玩 demo 是另外的需求。

## LOD 与绑定交接

先按 [LOD 交接](mesh-lod.md) 决定最终网格和烘焙材质；已有有效 LOD 直接复用。区分请求面数、返回面数和导入后三角面数。按 [服务绑定](service-rig.md) 保存服务任务状态并恢复原任务，长时间无新日志不构成重提理由；超时或未知状态先查询/恢复。

选一个校准空间正确的网格作为绑定基准，实际检查骨架层级、左右与手指语义，不能跨角色复制骨编号。下级 LOD 在同一坐标/休止姿态下可从基准转移权重；近邻表面插值可能跨衣层或身体两侧，转移后必须检查全身和目标动作。

依据目标引擎约束限制并归一化每顶点影响数，检查缺权重、非有限权重和骨组映射。不要把某次四影响限制写成所有引擎的固有要求。高模源、未绑定 LOD 与最终皮肤分别保存，禁止为简化导出覆盖原件。

## 动作和局部修复

先做目标 idle 或指定动作范围；肩、腋、掌腕、指尖和衣物接合区域查看全过程。基于实际求值网格检查三角面积变化、边长拉伸及尖刺，近退化休止三角形需单独归因。数值异常定位到面、顶点与骨权重后才局部修复；不能将单个案例的顶点 ID 或权重覆盖应用到其他角色。

对接近共线、几何连续但中间权重异常的点，可在明确局部条件下按空间位置插值相邻权重；保护其余区域，重新归一化并复查原失败帧及整个目标动作。不能把这条局部方法当任意穿模自动修复。衣物碰撞与皮肤拉伸是不同问题。

## 挂点和独立道具

根据真实手掌、背部和握持姿态放置命名 socket，记录父骨、局部位移/旋转、坐标轴和用途。静止挂点位置正确不代表动画中朝向正确，应在动作中检查。无蒙皮道具独立导出，原点放在实际握点并记录主轴；不把角色世界偏移烘进道具局部原点。

## 导出后回读

每个 LOD 检查骨架、绑定、材质、动作 clip 和挂点是否存在，米制身高、帧数/fps及首末循环正确。某些导入器生成骨骼显示用网格：通过 pose bone 的 custom_shape 对象引用识别并排除，不靠 Icosphere 等名称猜测。求尺寸和导出白名单均排除这些辅助对象，原工程可保留骨骼显示。

对全部交付 LOD 回读静止和动作帧；检查实际蒙皮网格尺寸，不把骨骼辅助网格 bbox 当角色身高。BLEND 图片打包，GLB 可独立加载。只在实际完成目标引擎测试后声称引擎验证通过；一段 idle 通过不代表任意动作都通过。

交付各 LOD GLB、可编辑工程、所需独立道具、动作/挂点约定、实测检查范围及按入口记录的业务阶段耗时。服务计算、客户端等待、本地处理分别列出，跳过的生成/绑定阶段不冒充本次执行。
