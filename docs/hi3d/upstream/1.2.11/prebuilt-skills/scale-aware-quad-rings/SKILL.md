# 尺度关联的低模四边面环带重制

适用于已有四边网格需要减少规则连续布线、保留特征线并建立粗细过渡的情况。不负责从照片生成几何，也不把 GLB 中的三角化预览当作可编辑四边面工程。

## 宿主执行模式

以 `$scale-aware-quad-rings` 或显式读取本文件调用。先读 [检查点](pcg/routes.yaml) 和 [阶段架构](pcg/architecture.yaml)。在 desktop 中先读 [Runtime 执行约定](../.dependency-run-tools/references/desktop-runtime.md)，并把 [宿主编排提示](../.dependency-pcg-view/references/host-orchestration.md) 注入编排 agent。执行前按 [打包约定](../.dependency-package-tools/references/usage.md) 和 [依赖清单](package.json) 在仓库外生成完整分发目录。

后台打开、导入、另存和预览渲染交接 [blender-tools](../.dependency-blender-tools/REFERENCE.md)，不另写 Blender 启动器。连通、边界、非流形和退化面调用 [mesh-audit](../.dependency-mesh-audit/REFERENCE.md) 的 `measure_mesh`。红黄灰划分、弦偏差和环带仍按本入口与阈值文件执行。

## 输入与基线

接收原始四边面工程、高精参考（如有）、目标面数或误差预算及原始闭环/部件边界。没有可编辑四边网格则先建立基线；缺少几何上可识别的缝线时请求用户标记，不凭纹理认定结构缝。记录原面数、面尺寸分布、尺度、连通片、边界和材质；保存可回退副本。

## 种子、保护和候选区

1. 本规范以原始四边面基准的世界坐标包围盒最大边定义 L，h 取基准所有边长的中位数；不得用表面积平方根代替 L，也不得在强融并后重新测量而改变阈值基准。总表面积 A 只用于覆盖比例统计。用 h/L、邻面法线转角、局部曲率相对背景值及连续特征边总长/L 筛选转角、折边和已确认的接缝。均匀四价点和新极点本身不是种子。
2. 红色硬保护：种子两侧必要的支撑面，原连续边链及面尺度尽量不动。仅沿面邻接加入仍有显著曲率剩余的支撑行，局部曲率降到背景即停止，并限制沿表面传播距离；逐片统计面积/A 和支撑行数。保护面积是结果，不反推固定覆盖配额。
3. 黄色缓曲区：不冻结网格，按允许的曲面弦偏差限制最大跨距。估计 e≈|k|max·s²/8，并沿原始边链采样实际弦偏差；超过预算则减小粗化倍率或改变融并方向。灰色平缓区才尝试大四边面。逐块评估，不从一条特征线无限扫描整片规则网格。
4. 开始前必读 [阈值与执行约束](references/hi3d-scale-aware-thresholds.md)。用户已确认的预设必须原样执行，不能默默替换误差预算或增加跨度宽限。本预设不是行业通用标准；其他物体若需要调整，先报告原因及新旧值。

## 审慎融并与环带

1. 先标出红黄灰分类和被保护的边链与转角。灰区逐片尝试较大面，黄色只限制粗化倍率，不把两者一起冻结。大块超限后必须降低倍率或细分片区重试，禁止将一次失败的大矩形整块从后续扫描中移除；只有局部重试仍不合格才保留，并记录面级原因。不可因过渡环成本高就把整片灰区当作保护区。
2. 沿粗网格内轮廓建立一至数圈连续四边面，边先顺轮廓环行，再逐圈增加周向分段并接到密网格外边界。逐圈检查内外边链闭合、交接段数与原边界连续性，不用从内圈同时射出大量分段。
3. 分段数不同时允许少量三价/五价等非四价点；将增段错开放入不同周向位置和相邻环层，避免内圈形成一排高价放射极点。检查实际顶点价数及局部密度，不能仅凭环带标签认为已实现分散。
4. 转角独立规划：先保持两侧直边轮廓和角点支撑，沿角区转向分配增段，检查转角附近挤压、扭曲及法线；直边的环带步距不可直接套在尖角。相邻片区的外环如合并，要作为合并环带检查，不声称仍是彼此独立的闭环。

## 验收与交付

在可编辑网格上逐片检查真实四边面、内外闭环、保护面及旧边界、非流形边、翻面与最小角、极点位置和密度；以原网格/高模比较表面误差和尺寸。按每个片区和环层分别数闭合边界，不把相邻环层的合并连通片当作单片失败或通过。必须另统计灰区/黄区/红区的原面保留数、修改表面积比例、新旧面面积比及仍未融并的具体原因，并用同相机线框对照；总面数下降不能代替灰区执行验收。区分“进入重制”与“面面积确实增大”，过渡带小面不能计为大面融并成功。纹理需检查贴图烘焙；GLB 为三角化预览，另交付 BLEND 或 OBJ 保存四边面。记录未通过的片区和阈值，局部回退而非覆盖原始文件。

## 验证示例

给一件带弯曲扶手和两个平缓矩形面片的四边网格，先识别扶手折边并保留相邻支撑行，再对平面片试做逐圈增段。成功时可观察到平面片面数下降、扶手边链仍连续、每个宣称独立的环带有两个闭合边界环、转角没有翻面，且可编辑工程全部为四边面；不达标的片区恢复原面。

## 阶段记录与预算

阶段记录遵从 [run-tools](../.dependency-run-tools/references/stage-records.md)，由执行者把真实起止、状态和耗时写到包外任务目录。本包没有自动计时脚本，token 无采集时标 unavailable。

融并和环带可能长时间占用 CPU，且期间可以没有业务产物。进入这些步骤前，任务目录必须已有预算和心跳；后台 Blender 由 [run-tools](../.dependency-run-tools/references/budget-run.md) 的 `process_run.run_budgeted` 启动。建议低档 120 秒（回读或预览）、中档 600 秒（单片融并）、高档 1800 秒（整模分区加环带）。低档可直接跑；中高档由宿主 `waiting_choice` 使用本入口 `choices_example` 确认后再启动。超时记 `interrupted`，不写半截工程。加时只在用户确认后用新输出目录和新的 `max_wall_seconds` 再跑。
